# nyaturingtest

一个会自己混群的 QQ 聊天 bot。它大部分时间在潜水看消息，有人叫它、@ 它或回复它时一定会回；
话题对上了也会自己插一句，但不会刷屏。

它会慢慢记住群友：谁喜欢什么、谁和谁是什么关系、群里有哪些梗。每天凌晨，它把这些零散的印象
整理成每个人的档案和一份群志。记错了被人纠正，它会把旧说法换掉，而不是对的错的一起记着。

基于 [shadow3aaa](https://github.com/shadow3aaa/) 的
[nonebot-plugin-nyaturingtest](https://github.com/shadow3aaa/nonebot-plugin-nyaturingtest) 二次开发，
运行在 NoneBot2 + OneBot V11 上，对话模型、Embedding 和 Rerank 都走云端 API。

## 聊起来是什么样

每个启用的群各自独立：有自己的人设、情绪、记忆和对群友的印象，互不串门。

- **被叫到就回。** 叫它的名字或别名、@ 它、回复它的消息，它都会接。
- **聊开了不会突然断。** 它说完话后 3 分钟内，刚才和它聊的人再开口，它会优先接住。
- **自己也会插话。** 群友聊得起劲、它插得上话的时候，会凑个热闹接一句。
- **冷场了会找话题。** 群里安静了两个小时以上，它会在合适的时段自己开个话题：工作日只在午饭和下班后，
  休息日白天到晚上，凌晨不打扰，一天最多两次；没人接话也不会自说自话。
- **不刷屏。** 最近的消息里它自己说的话超过两成，就不再主动插嘴；两次发言之间至少隔十几秒，一次最多发两条。
- **看得懂图。** 图片和表情包会直接交给模型看，看到的内容也会记进聊天记录里。
- **会用 QQ 表情。** 看得懂群友发的 QQ 表情和商城表情；偶尔在话后面带个表情，或者只回一个表情；
  也会给群友的消息贴表情回应（同一个群一分钟最多一次），有人给它的消息贴表情它也知道。
- **会戳一戳。** 看得到群里所有人的戳一戳（拍一拍），被戳了可能戳回去、回句话或者不理，
  大家都在戳某个人时也可能跟着戳一下；同一个群两分钟最多戳一次。
- **有情绪。** 群友的话会影响它的心情，也会影响它对每个人的印象，这些会反映在说话的语气上。

背后是两个模型分工：一个「观察者」负责读消息、判断要不要接话、记下值得记的事；
另一个「角色」只负责按人设把话说出来。

## 它怎么记住人

记忆分三层，越往下越长久：

1. **最近的聊天。** 最近 20 条消息，每次说话前都会看。
2. **记忆碎片。** 群里一段聊完、安静下来之后，观察者把整段从头读一遍，记成几条小结
   （比如「晚上几个人组队打 CS，语音沟通不畅连输几把」），再挑出少量以后还用得着的事，
   比如「A 最近在学吉他」「B 和 C 是同学」。每条都记着和谁有关、依据的是哪几条消息。
   说话前只翻和眼下在聊的人有关的那几条。碎片会过期：普通的事几个月后删掉，越重要的留得越久。
3. **档案和群志。** 每天凌晨 3:30，它把新攒下的碎片整理进每个人的档案（三百字左右）
   和这个群的群志（八百字左右），群志每晚都更新。碎片过期删掉之前，内容已经整理进去了，所以档案和群志是长久的记忆。
   和谁聊天时它会带上这个人的档案，群志则一直放在手边。

**记错了怎么办。** 它难免把人认错、把事记岔。有人明确纠正时，比如本人说「我不是……」，
或者有人指出它说错了并给出正确说法，它会删掉错的那条，换成更正后的说法；
当晚就重新整理相关的档案和群志，把旧说法一并去掉。玩笑、起哄和没有依据的说法不算纠正。

**不记什么。** 真实姓名、健康状况、住址、家人、金额、账号这类隐私，整理档案时会排除。

## 安装

把整个目录放进 NoneBot 项目的插件目录，并安装依赖：

- Python 3.10+
- `nonebot2[fastapi]`、`nonebot-adapter-onebot`、`nonebot-plugin-apscheduler`
- `tortoise-orm`、`openai`、`httpx`、`json-repair`
- `numpy`、`pillow`、`chinese-calendar`、`playwright`

Token 统计卡片用到同级目录下的公共绘图库 `plugins/utils/draw/plot.py`。
卡片需要的三个字体文件 `SourceHanSansCN-{Regular,Bold,Heavy}.ttf` 要放在数据目录 `data/nyaturingtest/` 下。

群志卡片是网页截图，需要 playwright 的 Chromium（`playwright install chromium`），
以及系统字体思源宋体、思源黑体（Debian 系装 `fonts-noto-cjk`）。

## 配置

复制 `config.example.json` 为 `config.json`，填上各家的 API Key：

| 段 | 用途 |
| --- | --- |
| `chat` | 角色模型：负责说话 |
| `feedback` | 观察者模型：负责判断、记忆和每晚整理 |
| `siliconflow_api_key` | Embedding 和 Rerank 共用的 Key |
| `embedding` | 记忆检索用的向量模型 |
| `rerank` | 检索结果重排，`threshold` 以下的结果丢弃 |
| `playwright_browsers_path` | 群志卡片用的 Chromium 所在目录，留空用 playwright 默认位置 |

`chat` 和 `feedback` 的 `base_url`、`model` 必填，其余缺省有默认值。改配置后要重启。
也可以用环境变量 `NYATURINGTEST_CONFIG_FILE` 指定别的配置文件，用 `NYATURINGTEST_DATA_DIR` 指定数据目录。

**角色预设**放在 `config/nyaturingtest/nya_presets/*.json`，包括人设、别名、设定条目和对话样例，
用 `/set_preset` 加载，新增或修改后不用重启。

## 命令

群聊命令除 `/查询记忆` 外都需要超级用户权限。

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/autochat enable` / `disable` | | 在本群启用或停用 |
| `/查询记忆 [@某人]` | `/memory` | 看看它对某人的印象，**所有群员都能用** |
| `/群志` | `/group_notes` `/查看群志` | 把本群群志做成图片发出来；新记忆攒够 10 条会先整理一遍 |
| `/status` | `/状态` | 当前状态、意愿值、队列和模型调用情况 |
| `/role` | `/当前角色` | 查看当前人设 |
| `/set_role <名字> <设定>` | `/设置角色` | 修改人设 |
| `/presets` | `/preset` | 列出可用预设 |
| `/set_preset <文件名>` | `/set_presets` | 加载预设 |
| `/calm` | `/冷静` | 让它冷静下来：情绪和印象归零，暂时不主动说话 |
| `/reset_emotion` | `/重置情绪` | 只重置情绪 |
| `/reset confirm` | `/重置 confirm` | 先备份，再清空本群的一切，**不可撤销** |
| `/rag_debug <内容>` | `/记忆诊断` | 看某句话能检索出哪些记忆 |
| `/token统计 [all]` | `/autochat token统计` | Token 用量卡片，加 `all` 统计全部历史 |
| `/backup_data` | `/备份数据` | 立刻备份一次 |
| `/help` | `/帮助` | 帮助 |

私聊也能管理，命令的第一个参数写群号，比如 `/status 123456`、`/reset 123456 confirm`；
另外有 `list_groups` 列出启用的群。

## 数据与备份

数据存在一个 SQLite 文件 `data/nyaturingtest/nyabot.sqlite` 里，包括聊天记录、记忆、档案和 Token 用量。

每天的定时任务：

| 时间 | 做什么 |
| --- | --- |
| 每 5 分钟 | 把聊完的一段整理成记忆 |
| 每 10 分钟 | 看看哪个群冷场了、要不要开个话题 |
| 03:00 | 清理 48 小时前的图片缓存 |
| 03:30 | 整理档案和群志，删除过期的记忆碎片 |
| 04:00 | 备份数据目录到 `data/nyaturingtest_backups/`，保留最近 3 份；清理 180 天前的聊天记录和 90 天前的 Token 明细 |

备份里有聊天内容、QQ 号和对群友的记忆，属于敏感数据，请妥善保存。
