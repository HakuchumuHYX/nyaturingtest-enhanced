# nyaturingtest

一个会自己混群的 QQ 聊天 bot。它大部分时间在潜水看消息，有人叫它、@ 它或回复它时一定会回；
话题对上了也会自己插一句，但不会刷屏。

它会慢慢记住群友：谁喜欢什么、谁和谁是什么关系、群里有哪些梗。每天凌晨，它把这些零散的印象
整理成每个人的档案和一份群志。记错了被人纠正，它会把旧说法换掉，而不是对的错的一起记着。

基于 [shadow3aaa](https://github.com/shadow3aaa/) 的
[nonebot-plugin-nyaturingtest](https://github.com/shadow3aaa/nonebot-plugin-nyaturingtest) 二次开发，
运行在 NoneBot2 + OneBot V11 上，对话模型、Embedding 和 Rerank 都走云端 API。

## 聊起来是什么样

每个启用的群各自独立：有自己的人设、心情、记忆和对群友的好感，互不串门。

- **被叫到就回。** 叫它的名字或别名、@ 它、回复它的消息，它都会接。
- **聊开了不会突然断。** 它说完话后 3 分钟内，刚才和它聊的人再开口，它会优先接住。
- **自己也会插话。** 群友聊得起劲、它插得上话的时候，会凑个热闹接一句。
- **冷场了会找话题。** 群里安静了两个小时以上，它会在合适的时段自己开个话题：工作日只在午饭和下班后，
  休息日白天到晚上，凌晨不打扰，一天最多两次；没人接话也不会自说自话。
- **不刷屏。** 插一句没人接就收住，不会自顾自接着说；最近的消息里它自己说的话超过两成，就不再主动插嘴；两次发言之间至少隔十几秒，一次最多发两条文字，另外最多一张表情包。
- **看得懂图。** 每张图片和表情包一进来就会被单独看一遍，描述记在那条消息里图原本的位置；
  有人回复某张图问它，它看的就是那一张。回话时还会再看原图。同一张表情包看过一次就记住了，30 天内不会重看。
- **会点开转发。** 群友发的合并转发，它会在后台把里面的文字和图都看一遍，读完再决定接不接话；
  分享卡片能看到标题，语音、视频、文件只知道有这么一条。
- **知道撤回。** 有人撤回消息，它记下的那条也会变成「撤回了一条消息」，看不到原文。
- **会发表情包。** 群友发的表情包，能拿来回应人的它会自己收藏起来（截图、照片之类的不收），所有群共用一个库；
  聊天时可以只甩一张，也可以说完话再补一张，同一个群两分钟最多一张。发错了图，超级用户回复那张图发 `stickerdel` 就能删掉并拉黑。
- **懂 QQ 表情。** 看得懂群友发的 QQ 表情和商城表情；会给群友的消息贴表情回应（同一个群一分钟最多一次），
  有人给它的消息贴表情它也知道。
- **会戳一戳。** 看得到群里所有人的戳一戳（拍一拍），被戳了可能戳回去、回句话或者不理，
  大家都在戳某个人时也可能跟着戳一下；同一个群两分钟最多戳一次。
- **有心情，也记好感。** 群友的话会影响它此刻的心情（过几个小时会自己平复），也会一点点改变它对每个人的好感；两者都会反映在说话的语气上。好感度是长期养成的，不会随时间消失，只有讨厌会慢慢淡掉。

背后是两个模型分工：一个「观察者」负责读消息、判断要不要接话、记下值得记的事；
另一个「角色」只负责按人设把话说出来。

## 它怎么记住人

记忆分三层，越往下越长久：

1. **最近的聊天。** 最近 20 条消息，每次说话前都会看。
2. **记忆碎片。** 群里一段聊完、安静下来之后，观察者把整段从头读一遍，记成几条小结
   （比如「晚上几个人组队打 CS，语音沟通不畅连输几把」），再挑出少量以后还用得着的事，
   比如「A 最近在学吉他」「B 和 C 是同学」。每条都记着和谁有关、依据的是哪几条消息。
   说话前只翻和眼下在聊的人有关的那几条。碎片会过期：普通的事几个月后删掉，越重要的留得越久。
3. **档案和群志。** 每天凌晨 3:30，它把新攒下的碎片整理进每个人的档案（三百字左右）
   和这个群的群志（八百字左右），群志每晚都更新。碎片过期删掉之前，内容已经整理进去了，所以档案和群志是长久的记忆。
   和谁聊天时它会带上这个人的档案，群志则一直放在手边。

**记错了怎么办。** 它难免把人认错、把事记岔。有人明确纠正时，比如本人说「我不是……」，
或者有人指出它说错了并给出正确说法，它会删掉错的那条，换成更正后的说法；
当晚就重新整理相关的档案和群志，把旧说法一并去掉。玩笑、起哄和没有依据的说法不算纠正。

**不记什么。** 真实姓名、健康状况、住址、家人、金额、账号这类隐私，整理档案时会排除。

## 它怎么长大

人设只是出发点。每天凌晨整理完档案和群志，它还会整理自己：

- **人生线**：每个人设一份，各群共享。身份阶段按日期往前走（开学 → 期末 → 升年级 → ……），
  收进它在各群说过的关于自己的事，近况、性格、说话方式、喜好跟着变。
- **群里的它**：每个群一份。在这个群沾上的口癖和梗、和这个群的关系、对群友说过的话和答应的事。
  只用本群的聊天整理，不出群，也改不了人生线里的事实。

性格只跟着群友的影响和生活里的事变，不拿它自己说过的话当证据，免得越说越极端。
在一个群里沾上很久、或者好几个群都有的说话方式，会慢慢变成它整体的样子。
底线和固定信息（比如生日）写在预设里，整理改不了。`/persona` 会发一张图：这两层、最近的改动，还有一把从出发点量到今天的成长尺。
整理用的是 `feedback` 模型，换模型会改变它长大的方式（有的模型学得太快、会记混事），换之前先用回放脚本试跑一个月。

## 安装

把整个目录放进 NoneBot 项目的插件目录，并安装依赖：

- Python 3.10+
- `nonebot2[fastapi]`、`nonebot-adapter-onebot`、`nonebot-plugin-apscheduler`
- `tortoise-orm`、`openai`、`httpx`、`json-repair`
- `numpy`、`pillow`、`chinese-calendar`、`playwright`

群志卡片和 Token 统计卡片都是网页截图，需要 playwright 的 Chromium（`playwright install chromium`），
以及系统字体思源宋体、思源黑体（Debian 系装 `fonts-noto-cjk`）。

## 配置

复制 `config.example.json` 为 `config.json`，填上各家的 API Key：

| 段 | 用途 |
| --- | --- |
| `chat` | 角色模型：负责说话 |
| `feedback` | 观察者模型：负责判断、记忆和每晚整理 |
| `siliconflow_api_key` | Embedding 和 Rerank 共用的 Key |
| `embedding` | 记忆检索用的向量模型 |
| `rerank` | 检索结果重排，`threshold` 以下的结果丢弃 |
| `playwright_browsers_path` | 卡片截图用的 Chromium 所在目录，留空用 playwright 默认位置 |

`chat` 和 `feedback` 的 `base_url`、`model` 必填，其余缺省有默认值。改配置后要重启。
也可以用环境变量 `NYATURINGTEST_CONFIG_FILE` 指定别的配置文件，用 `NYATURINGTEST_DATA_DIR` 指定数据目录。

**角色预设**放在 `config/nyaturingtest/nya_presets/*.json`，用 `/set_preset <文件名>` 加载。
没设人设的群只记消息、不说话；目录里一个可用的人设文件都没有时，启动会报 warning。格式：

```json
{
    "name": "小明",
    "aliases": ["明明"],
    "as_of": "2025-09",
    "seed": "我是一名大一新生，刚开学……（第一人称，写清身份、性格、说话方式、喜好）",
    "profile": ["2006 年 1 月 1 日出生"],
    "bottom_lines": [
        "不输出色情或擦边内容，也不配合这类要求",
        "不泄露群友隐私，不把一个群的事带到另一个群"
    ],
    "knowledges": ["静态常识，每轮原样注入"],
    "hidden": false
}
```

| 字段 | 说明 |
| --- | --- |
| `name` / `aliases` | 名字和别名，群友叫到就算在叫它 |
| `as_of` | 出发点的年月，人生线按它和今天的日期推算走到了哪一步 |
| `seed` | 出发点：`as_of` 时的它是什么样的人，只作每日整理的参照，聊天时用的是整理出的人生线 |
| `profile` | 不会变的固定信息，聊天时原样给出，整理不会改 |
| `bottom_lines` | 底线，聊天和整理都不能违背 |
| `knowledges` | 静态常识，每轮原样注入 |
| `hidden` | 为 `true` 时不出现在 `/presets` 列表里 |

改了预设后重启，或在群里重新 `/set_preset`，才对已加载的群生效。

## 命令

群聊命令除 `/查询记忆` 外都需要超级用户权限。

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/autochat enable` / `disable` | | 在本群启用或停用 |
| `/查询记忆 [@某人]` | `/memory` | 看看它手账里关于某人的那一页（印象、记得的事、好感度），发图片，**所有群员都能用** |
| `/群志` | `/group_notes` `/查看群志` | 把本群群志做成图片发出来；新记忆攒够 10 条会先整理一遍 |
| `/status` | `/状态` | 当前状态、意愿值、队列和模型调用情况 |
| `/presets` | `/preset` | 列出可用预设 |
| `/set_preset <文件名>` | `/set_presets` | 加载预设 |
| `/persona` | `/人设` | 把人生线、本群的它和最近的改动做成图片发出来 |
| `/calm` | `/冷静` | 让它冷静下来：心情回到平静，暂时不主动说话 |
| `/reset_emotion` | `/重置情绪` | 只重置心情，不动好感度 |
| `/reset confirm` | `/重置 confirm` | 先备份，再清空本群的消息、记忆、档案、群志和群里的它，人设保留，**不可撤销** |
| `/rag_debug <内容>` | `/记忆诊断` | 看某句话能检索出哪些记忆 |
| `/token统计` | `/autochat token统计` | 当前 chat / feedback 模型的 Token 用量卡片 |
| `stickerdel` | | 回复一条带图的消息：把图从表情包库删掉并拉黑，以后见到只看不收 |
| `/backup_data` | `/备份数据` | 立刻备份一次 |
| `/help` | `/帮助` | 帮助 |

私聊也能管理，命令的第一个参数写群号，比如 `/status 123456`、`/reset 123456 confirm`；
另外有 `list_groups` 列出启用的群。

## 数据与备份

数据存在一个 SQLite 文件 `data/nyaturingtest/nyabot.sqlite` 里，包括聊天记录、记忆、档案、表情包标签和 Token 用量；
表情包图片在 `data/nyaturingtest/stickers/`，和数据库一起备份。

每天的定时任务：

| 时间 | 做什么 |
| --- | --- |
| 每 5 分钟 | 把聊完的一段整理成记忆 |
| 每 10 分钟 | 看看哪个群冷场了、要不要开个话题 |
| 03:00 | 清理 48 小时前的图片缓存 |
| 03:30 | 整理档案和群志，整理人生线和各群的它，删除过期的记忆碎片 |
| 04:00 | 备份数据目录到 `data/nyaturingtest_backups/`，保留最近 1 份；清理 180 天前的聊天记录和 90 天前的 Token 明细 |

备份里有聊天内容、QQ 号和对群友的记忆，属于敏感数据，请妥善保存。

## 日志

插件的日志级别跟随 `.env` 的 `LOG_LEVEL`：

- `INFO`：每轮说不说（`speak_decision`）、发出的话（`reply`）、贴表情、记忆写入、定时整理结果。
- `DEBUG`：再加上收到的消息（`message`）、检索统计、每次模型调用、看图，顺着 `message` → `speak_decision` → `reply` 能读出一轮是怎么走的。

NoneBot 自己在 INFO/DEBUG 会给每条消息打十几行匹配器调度日志，开 `DEBUG` 时很吵。想只压掉它们，可以在 `bot.py` 里
`nonebot.init()` 之前换掉默认的日志输出，其他插件不受影响：

```python
import sys

from nonebot.log import default_format, logger, logger_id

# NoneBot 内核、适配器、uvicorn 和 websockets 只留 WARNING 起，其余来源（包括所有插件）跟随 LOG_LEVEL；
# 连上时插件自己会记一行「Bot N 已连接」
NOISY_SOURCES = {"nonebot", "uvicorn", "websockets"}


def _log_filter(record) -> bool:
    level = (
        "WARNING"
        if record["name"] in NOISY_SOURCES
        else record["extra"].get("nonebot_log_level", "INFO")
    )
    return record["level"].no >= logger.level(level).no


logger.remove(logger_id)
logger.add(sys.stdout, level=0, diagnose=False, filter=_log_filter, format=default_format)
```

压掉之后，收到消息的原文（NoneBot 的 SUCCESS 行）也不再输出，插件的 `message` 记的是转换后的文字（图片已换成描述）。
